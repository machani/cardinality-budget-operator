# v0.2: Enforce mode

Goal: safe enforcement with undo, drift handling, pause and resume, and the kill switch. Lab cluster only.
Rows are in build order. ADRs to read first: 0007, 0010 (kill switch part), 0006, 0009, 0008.

The kill switch (F-0203) is built into the write layer before any code path that adds or removes drops, and the
finalizer (F-0204) exists before the first drop, so every drop always has a way back.
