## Notes

(Blockers, open `TODO(machani)` choices and anything worth remembering.)

- IDs were renumbered once on 2026-10-10, before any work started, to match build order. From now on they never
  change.
- Decided 2026-10-12 ([ADR 0015](../adr/0015-events-and-condition-reasons.md)): every mode records one Event
  per state change; Observe = status + Events, Warn adds `plannedDrops`.
- Open `TODO(machani)` in `internal/controller/status.go`: `plannedDrops` is filled from the warn threshold on
  (lead time) rather than only at 100%.
- `kubectl describe` only shows Events still kept by the API server (1 hour by default, `--event-ttl`). Status is
  the lasting record; Events are the recent history.
- F-0109 error handling (decided 2026-10-12). Returning an error makes controller-runtime retry with
  exponential backoff and ignore `RequeueAfter`; so only unexpected API failures are returned as errors.
  `Result.Requeue` is deprecated in controller-runtime v0.25, so conflicts use a short `RequeueAfter`.

  | Case | Return | Why |
  | --- | --- | --- |
  | Budget not found (deleted) | `Result{}, nil`; its metrics are removed | Nothing left to do |
  | Backend unreachable, warming up, partial, stale | Status `Unknown`, `RequeueAfter` measure interval, `nil` | Expected state; must show in status; backoff would hammer a struggling Prometheus (ADR 0005) |
  | Conflict on status or monitor write | `RequeueAfter: 1s`, `nil` | Normal optimistic locking (ADR 0007) |
  | Other API errors (get budget, status patch) | `Result{}, err` | Unexpected; backoff and `reconcile_errors_total` alert |
  | Success | `RequeueAfter` with ±10% jitter, `nil` | HLD reconcile step 8 |
- Status writes do not trigger a reconcile (GenerationChanged or AnnotationChanged predicate); without it each
  status patch would cause an immediate new measurement.
- Decided 2026-10-10 ([ADR 0012](../adr/0012-protected-metrics-validation.md)): invalid `protectedMetrics`
  patterns are caught in CEL where supported and always at runtime (`Ready=False/InvalidSpec`, freeze).
  Patterns are fully anchored. Phase 1 fact #9 decides whether the CEL regex check is possible.
