## Notes

(Blockers, open `TODO(machani)` choices and anything worth remembering.)

- IDs were renumbered once on 2026-10-10, before any work started, to match build order. From now on they never
  change.
- Open question: the HLD reconcile loop says Observe mode is "status only", so an Observe budget shows no Events
  in `kubectl describe`, not even when the backend goes unreachable. Decide whether that is intended before F-0111.
- `kubectl describe` only shows Events still kept by the API server (1 hour by default, `--event-ttl`). Status is
  the lasting record; Events are the recent history.
- F-0109 error handling (proposed, confirm before coding). Returning an error makes controller-runtime retry with
  exponential backoff and ignore `RequeueAfter`; so only unexpected API failures are returned as errors.

  | Case | Return | Why |
  | --- | --- | --- |
  | Budget not found (deleted) | `Result{}, nil` | Nothing left to do |
  | Backend unreachable, warming up, partial, stale | Status `Unknown`, `RequeueAfter` measure interval, `nil` | Expected state; must show in status; backoff would hammer a struggling Prometheus (ADR 0005) |
  | Conflict on status or monitor write | `Result{Requeue: true}, nil` (or the error) | Normal optimistic locking (ADR 0007) |
  | Other API errors (status patch, list monitors) | `Result{}, err` | Unexpected; backoff and `reconcile_errors_total` alert |
  | Success | `RequeueAfter` with jitter, `nil` | HLD reconcile step 8 |
- Decided 2026-10-10 ([ADR 0012](../adr/0012-protected-metrics-validation.md)): invalid `protectedMetrics`
  patterns are caught in CEL where supported and always at runtime (`Ready=False/InvalidSpec`, freeze).
  Patterns are fully anchored. Phase 1 fact #9 decides whether the CEL regex check is possible.
